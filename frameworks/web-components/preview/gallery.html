Web Components

The shared sixteen as light-DOM custom elements. No build step, no runtime dependency, no shadow root — <mue-*> upgrades the markup you write and applies the same classes the vanilla previews use, so the one stylesheet styles every framework.

Name: Web Components bindings
Package: mue-web-components (frameworks/web-components)
Install: <script type="module" src="frameworks/web-components/index.js">
Runtime dependency: none (custom elements + the shared sheet)
Shadow DOM: no — light DOM, so document classes apply
Defined in: styles/components.css (classes only)
License: MIT

2 · Input

mue-input owns the label/helper/error structure: label is joined by for/id, state="error" sets aria-invalid and points aria-describedby at the message. Emits mue-change.

3 · Textarea

mue-textarea is the same field contract as the input, plus rows.

4 · Select

mue-select upgrades the authored <option>s into a native <select>, so OS type-ahead and screen readers keep working untouched.

5 · Checkbox

mue-checkbox keeps a native input inside its own label, so Space toggles and the checked state is announced; each change emits mue-change.

6 · Radio group

mue-radio-group wraps mue-radio options in a labelled <fieldset> and shares one name, so arrow keys move the choice.

7 · Switch

mue-switch is a native checkbox given role="switch" and aria-checked; the visible track is decorative. Space flips it.

9 · Badge

mue-badge conveys state through text, not colour alone; the optional dot is aria-hidden.

10 · Avatar

mue-avatar renders an image (keeps alt) or real-text initials; mue-avatar-group stacks them under a labelled role="group".

11 · Dialog

mue-dialog traps focus, closes on Escape and returns it to the trigger; [slot="footer"] children move into the dialog footer.

Nothing is claimed to work until the headless check has actually run against it. This dialog is that element, with its own title, close control and focus trap.

12 · Dropdown

mue-dropdown follows the menu pattern: the trigger carries aria-haspopup/aria-expanded, arrows walk the rows, and choosing one emits mue-select then closes.

13 · Tabs

mue-tabs pairs each mue-tab with the mue-tabpanel at the same index and marks its tablist data-mue-bound, so the vanilla script never double-wires it. Arrow keys move focus, Home/End jump, Enter/Space activate.

Markup Classes Tokens

Every class is defined in styles/components.css — the parity audit rejects any that are not.

Colour, radius, spacing and motion come from design-tokens.
