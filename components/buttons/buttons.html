Buttons

Action triggers with six semantic variants, three sizes and a press response that stays under the finger. Every rule lives in the shared sheet, so the markup below is the whole component.

Name: Buttons
Category: buttons
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #buttons
Variants: primary, secondary, outline, ghost, danger, success, link, icon
Sizes: sm, base, lg (44 / 44 / 52px tall)
Responsive: full-width below 640px, larger tap targets on touch
Dependencies: none
License: MIT

Variants

Variant carries meaning, not decoration: primary is the one action per view, secondary and outline are peers, ghost disappears into a toolbar, danger and success state an outcome.

Solid

Quiet

Icon-only

Tab through the row: the focus ring is the same recipe everywhere, 2px outline plus a 3px soft halo from --ring-focus.

Sizes

Height is the tap target, so it is fixed by token rather than by padding arithmetic.

States

Disabled dims without disappearing; loading sweeps over the label and keeps the button its original width so nothing around it moves.

Accessibility & motion

  • 44px minimum height, 52px on touch devices where hover is unreliable
  • Icon-only buttons require an aria-label; decorative SVGs are aria-hidden
  • Press travels 1px downward on :active, so a click is felt before it is read
  • Hover lift uses --lift-hover-sm; under prefers-reduced-motion movement tokens collapse to zero
  • Disabled buttons keep :disabled styling and block pointer events
Markup

<button class="btn-outline" type="button">Outline</button>

<button class="btn-primary" type="button" disabled>Disabled</button>
<button class="btn-primary loading" type="button" aria-busy="true">
  <span class="bar"></span>Saving…
