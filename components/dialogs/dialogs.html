Dialogs

Modal overlays that require user confirmation or input before continuing. The markup carries the behaviour hooks — data-open, data-close, data-dialog — so no page script is needed.

Name: Dialogs
Category: dialogs
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #overlays
Behaviour: styles/mue.js — [data-open], [data-close], [data-dialog]
Variants: confirm, alert, custom
Responsive: bottom sheet below 640px, full-width footer buttons
Dependencies: none
License: MIT

Confirm dialog

A confirmation names the consequence and puts the destructive action on the right, so the safe choice is the one under the thumb when the dialog lands.

Delete project?
This will permanently delete all data associated with the project. This action cannot be undone.

Alert dialog

One decision, two ways out. The footer keeps its own order while the sheet handles the wrap, so nothing overflows at 320px.

Unsaved changes
You have unsaved changes. Would you like to save them before leaving?

Keyboard behavior

  • Escape closes the topmost open dialog
  • Clicking the scrim (anything that is not the panel) closes it
  • Tab is trapped inside the panel while it is open, then focus returns to the trigger
  • html.mue-locked stops the page scrolling behind the dialog
  • A closed dialog is visibility: hidden, so it can never be tabbed into

Accessibility

  • role="dialog" or role="alertdialog" with aria-modal="true"
  • aria-labelledby points at the title, so the dialog announces itself
  • The close button is an empty-looking glyph, so it carries an aria-label
  • The scrim blocks interaction with background content while open
  • Under prefers-reduced-motion the movement tokens collapse to zero and the dialog simply appears
Markup
<button class="btn-primary" type="button" data-open="#dlg-confirm" aria-haspopup="dialog">
  Delete project
</button>

<div class="overlay">
  <div class="dialog" id="dlg-confirm" data-dialog role="dialog"
       aria-modal="true" aria-labelledby="dlg-title">
    <div class="dialog-header">
      <span class="dialog-title" id="dlg-title">Delete project?</span>
      <button class="dialog-close" type="button" data-close aria-label="Close dialog">&times;</button>
    </div>
    <div class="dialog-body">...</div>
    <div class="dialog-footer">
      <button class="btn-outline" type="button" data-close>Cancel</button>
      <button class="btn-danger" type="button" data-close>Delete project</button>
    </div>
  </div>
</div>
