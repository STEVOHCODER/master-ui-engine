Header Navigation

Top app header with brand, navigation, and user actions.

Name: Header Navigation
Category: navigation
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #navigation (+ #buttons, #display)
Variants: default, with user profile
Responsive: yes — hamburger drawer below 768px

License: MIT

Default

Brand
  • Dashboard
  • Projects

  • Settings
JS

Responsive behavior

Below 768px the links collapse behind the hamburger, which reveals a full-width drawer (the .is-open class on .nav-links). Scroll past 8px and the header gains a shadow through .is-scrolled. Both behaviours are wired by styles/mue.js — no page script.

Accessibility

  • <header role="banner"> landmark
  • The hamburger uses aria-expanded and aria-controls pointing at the list
  • Links are 44px tall with a visible focus ring
  • A skip link is recommended in a real app (not shown)
