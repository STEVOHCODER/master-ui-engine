Tabs

Group related content into separate views accessible via tab navigation.

Name: Tabs
Category: navigation
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #tabs
Variants: underline (default); .pills / .segmented also available in the region
Responsive: yes — horizontally scrollable tablist on mobile
Dependencies: styles/components.css, styles/mue.js (roving tabindex + arrow keys)
License: MIT

Default

Overview

A high-level summary of the selected item with key metrics and recent activity.

Details

Detailed specifications, attributes, and configuration options.

Settings

Preferences and controls for customizing behavior.

Keyboard behavior

  • Arrow keys move focus between tabs (managed by styles/mue.js)
  • Enter/Space activates the focused tab
  • Only the active tab is in the tab order — mue.js applies a roving tabindex
  • Each panel is hidden via the hidden attribute, driven by aria-controls

Responsive behavior

Below 640px the tablist scrolls horizontally while remaining a set of 44px tap targets — the overflow-x:auto in the #tabs region handles this.

Accessibility

  • role="tablist", role="tab", role="tabpanel" with aria-controls/aria-labelledby
  • aria-selected marks the active tab; the sheet paints the ink bar
  • Keyboard navigable per the WAI-ARIA tabs pattern
Markup
<div class="tabs">
  <div class="tab-list" role="tablist" aria-label="Item views">
    <button class="tab" role="tab" aria-controls="panel-overview" aria-selected="true">Overview</button>
    <button class="tab" role="tab" aria-controls="panel-details" aria-selected="false" tabindex="-1">Details</button>
  </div>
  <div class="tab-panel" id="panel-overview" role="tabpanel"><h3>Overview</h3></div>
  <div class="tab-panel" id="panel-details" role="tabpanel" hidden><h3>Details</h3></div>
</div>
