Breadcrumbs

Show the current location within a hierarchy and allow navigation up levels.

Name: Breadcrumbs
Category: navigation
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #navigation
Variants: default, compact
Responsive: yes — the trail wraps onto new lines on narrow screens
Dependencies: styles/components.css, styles/mue.js
License: MIT

Default

Home› Products› Software› Analytics dashboard

Compact

Home/ Dashboard/ Settings

Accessibility

  • <nav aria-label="Breadcrumb"> landmark
  • The current page uses aria-current="page"
  • Separators are hidden from screen readers with aria-hidden="true"
Markup
<nav class="breadcrumbs" aria-label="Breadcrumb">
  <a href="#">Home</a>
  <span class="separator" aria-hidden="true">&rsaquo;</span>
  <a href="#">Products</a>
  <span class="separator" aria-hidden="true">&rsaquo;</span>
  <span aria-current="page">Analytics</span>
</nav>
