Pagination

Navigate through large sets of content one page at a time.

Name: Pagination
Category: navigation
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #navigation
Variants: default, with ellipsis
Sizes: 44px tap targets via --control-h
Responsive: yes — wraps onto new lines and centres below 480px
Dependencies: styles/components.css, styles/mue.js
License: MIT

Responsive behavior

On narrow screens the row wraps and centres; for very large sets prefer a "load more" pattern over long number runs.

Accessibility

  • <nav> landmark with aria-label="Pagination"
  • The current page carries aria-current="true", styled by the sheet
  • Disabled cells use the native disabled attribute, so they drop out of the tab order
  • Every cell is a 44px tap target with a visible focus ring
Markup
<nav class="pagination" aria-label="Pagination">
  <button type="button" disabled aria-label="Previous">←</button>
  <button type="button">1</button>
  <button type="button" aria-current="true">2</button>
  <span class="ellipsis" aria-hidden="true">&#8230;</span>
  <button type="button" aria-label="Next">→</button>
</nav>
