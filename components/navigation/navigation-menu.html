Navigation Menu

Primary navigation with optional dropdowns and active states.

Name: Navigation Menu
Category: navigation
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #navigation + #dropdown
Variants: default, with dropdown, active state
Responsive: yes — hamburger drawer below 768px
Dependencies: styles/components.css, styles/mue.js (drawer + [data-dropdown] menus)
License: MIT

Default

  • Dashboard
  • Projects
  • Team
  • Settings

With dropdown

  • Dashboard
    • Documentation
    • Templates
    • Design systems
  • Team
  • Settings

Responsive behavior

Below 768px the list collapses behind the hamburger into a stacked drawer (styles/components.css #navigation); each cell keeps a 44px height. Dropdowns are toggled by [data-dropdown] — styles/mue.js handles open/close, Esc and arrow navigation.

Accessibility

  • <nav aria-label> landmark
  • Dropdown triggers expose aria-haspopup/aria-expanded and support Esc + arrow keys via styles/mue.js
  • Active state combines colour and background, not colour alone
Markup
<nav class="navbar" aria-label="Main navigation">
  <ul class="nav-links" id="navLinks">
    <li class="nav-item"><a class="nav-link" href="#" aria-current="page">Dashboard</a></li>
    <li class="nav-item">
      <div class="dropdown">
        <button class="nav-link" type="button" data-dropdown aria-haspopup="true" aria-expanded="false">Resources</button>
        <ul class="dropdown-menu">
          <li><a class="menu-item" href="#">Documentation</a></li>
          <li><a class="menu-item" href="#">Templates</a></li>
        </ul>
      </div>
    </li>
  </ul>
  <div class="nav-spacer"></div>
  <button class="hamburger" type="button" data-menu-toggle="navLinks"
          aria-controls="navLinks" aria-expanded="false" aria-label="Toggle navigation">&#9776;</button>
</nav>
