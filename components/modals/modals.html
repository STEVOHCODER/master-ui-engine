Modals

Focused overlays for creating, editing, or reviewing content without leaving the page. Header, scrolling body and pinned footer are slots; the shared sheet sizes them and the shared script drives them.

Name: Modals
Category: modals
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #overlays (+ #fields, #buttons)
Behaviour: styles/mue.js — [data-open], [data-close], [data-dialog]
Variants: create item, edit item, form modal
Width: --modal-w override on the panel (35rem here, 32rem by default)
Responsive: bottom sheet below 640px, body scrolls past 85vh
Dependencies: none
License: MIT

Create item modal

A form modal keeps its footer pinned while the body scrolls, so the Create button is always where the reader left it. Fields are plain .field blocks — the modal adds no form CSS of its own.

Add new item

The item will be added to your current list.

Keyboard behavior

  • Escape closes the modal
  • Tab cycles focus within modal contents, wrapping at both ends
  • Focus lands on the first control when the modal opens and returns to the trigger when it closes
  • Close button and scrim both dismiss; the page behind is scroll-locked

Accessibility

  • role="dialog", aria-modal="true", aria-labelledby on the panel
  • Every input has an associated .field-label — placeholder text is not a label
  • The close glyph carries an aria-label; the scrim never receives focus
  • A closed modal is visibility: hidden, so its inputs are unreachable by keyboard
  • Body text scrolls inside the panel rather than growing the page
Markup
<button class="btn-primary" type="button" data-open="#modal-create" aria-haspopup="dialog">
  Add new item
</button>

<div class="overlay">
  <div class="modal" id="modal-create" data-dialog role="dialog" aria-modal="true"
       aria-labelledby="modal-title" style="--modal-w: 35rem">
    <div class="modal-header">
      <span class="modal-title" id="modal-title">Add new item</span>
      <button class="modal-close" type="button" data-close aria-label="Close dialog">&times;</button>
    </div>
    <div class="modal-body">
      <div class="stack">
        <div class="field">
          <label class="field-label" for="item-name">Item name</label>
          <input id="item-name" type="text" placeholder="Enter name">
        </div>
      </div>
    </div>
    <div class="modal-footer">
      <button class="btn-outline" type="button" data-close>Cancel</button>
      <button class="btn-primary" type="button" data-close>Create item</button>
    </div>
  </div>
</div>
