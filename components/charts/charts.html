Responsive behavior

The .chart frame is a flex column with min-width:0, and .chart svg is width:100%; height:auto, so the artwork keeps its viewBox ratio at any width — two charts side by side in a .grid-auto simply stack once a column no longer fits, with no breakpoint of their own.

Accessibility

  • <svg role="img"> with <title> and <desc> for screen readers
  • Color is not the only means of conveying data (bars + positions + axis labels)
  • Keyboard focusable containers where interactive
  • Bars grow on --duration-slower and the line draws on --duration-slowest; both easing tokens collapse to near-zero under prefers-reduced-motion

    <span class="legend-item"><span class="legend-dot" style="background:var(--primary-bg)"></span>Signups</span>
