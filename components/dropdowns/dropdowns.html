Dropdowns

Reveal a list of actions or options on demand, triggered by a button. The trigger only needs data-dropdown; open, close, Escape, outside click and arrow-key walking all come from styles/mue.js.

Name: Dropdowns
Category: dropdowns
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #dropdown (+ #buttons for the trigger)
Behaviour: styles/mue.js — [data-dropdown]
Variants: default, with icons, danger action, divider
Responsive: menu width min(20rem, 90vw); anchored to the trigger
Dependencies: none
License: MIT

Default

Rows are buttons, not links, because they fire an action. .menu-divider groups them and .menu-item.danger tints the one row that cannot be undone.

Keyboard behavior

  • Enter/Space on the trigger opens the menu; opening moves focus to the first row
  • Arrow keys walk the rows and wrap at both ends
  • Escape closes the menu and returns focus to the trigger
  • A click anywhere outside the .dropdown closes it

Accessibility

  • aria-haspopup="true" on the trigger; aria-expanded is kept in sync by the script
  • Menu rows are real focusable buttons, so the 44px row and the tint hover state arrive together
  • Decorative icons are aria-hidden; the label carries the meaning
  • A hidden menu is opacity: 0; pointer-events: none, never display: none, so it can fade in and out
Markup
<div class="dropdown">
  <button class="btn-outline" type="button" data-dropdown
          aria-haspopup="true" aria-expanded="false">
    Actions <svg viewBox="0 0 24 24" aria-hidden="true">...</svg>
  </button>
  <ul class="dropdown-menu">
    <li><button class="menu-item" type="button">Edit</button></li>
    <li><button class="menu-item" type="button">Duplicate</button></li>
    <li><div class="menu-divider"></div></li>
    <li><button class="menu-item danger" type="button">Delete</button></li>
  </ul>
</div>
