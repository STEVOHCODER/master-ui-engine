Radio Buttons

Select one option from a mutually exclusive group.

Name: Radio Buttons
Category: forms
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #choice
Design system: MASTER-UI-ENGINE custom
Variants: default, selected, disabled
Responsive: yes — stacks vertically
Dependencies: none (native radio inputs, no JS)
Original source: MASTER-UI-ENGINE (original)
License: MIT

Default

Each option is a label wrapping a real radio input, so exclusivity comes from the shared name attribute and the browser handles arrow-key navigation for free. The visible circle is .box; its dot is a pseudo-element that scales in on --ease-spring.

Plan

Disabled

A disabled option stays in the group — it is still part of the answer set, it just cannot be picked, and it drops out of the tab order. Keep at least one enabled choice, otherwise the group is unreadable.

Visibility

Accessibility

  • <fieldset> + <legend> name the question the group answers
  • The same name attribute makes the options mutually exclusive
  • Checked state is announced by screen readers because the inputs are real, only visually hidden
  • Focus lands on the visible circle via input:focus-visible + .box, so keyboard order is obvious
  • Rows are --control-h tall, so the group is a comfortable touch target
Markup
<fieldset class="radiogroup">
  <legend>Plan</legend>
  <label class="radio">
    <input type="radio" name="plan" value="starter">
    <span class="box" aria-hidden="true"></span>
    <span>Starter — $19/mo</span>
  </label>
  <label class="radio">
    <input type="radio" name="plan" value="pro" checked>
    <span class="box" aria-hidden="true"></span>
    <span>Professional — $49/mo</span>
  </label>
</fieldset>
