Checkboxes

Toggle one or more independent options from a group.

Name: Checkboxes
Category: forms
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #choice
Design system: MASTER-UI-ENGINE custom
Variants: default, checked, disabled, with description
Responsive: yes — stacks vertically
Dependencies: none (native input, no JS)
Original source: MASTER-UI-ENGINE (original)
License: MIT

Default

A native <input type="checkbox"> is hidden inside the label and the visible box is painted from its :checked state, so toggling, keyboard focus and screen-reader announcements stay free — no behaviour code on this page. The tick is an SVG that scales in with --ease-spring.

Responsive behavior

Each row is a wrapping flex label with a 44px minimum height (--control-h), and the box is flex:none, so a long label breaks onto its own line instead of squeezing the box or overflowing at 320px. The group itself is a plain column, so it stacks on every screen.

Accessibility

  • Native <input type="checkbox"> wrapped in its own <label>, so the whole row is clickable
  • Checked state announced by screen readers because the input is real, only visually hidden
  • Focus ring is drawn on the visible box via input:focus-visible + .box
  • The decorative tick SVG is aria-hidden; the box carries no text
  • Disabled checkboxes are non-focusable and dimmed
