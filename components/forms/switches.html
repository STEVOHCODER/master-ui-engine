Switches

Toggle a single setting on or off — ideal for preferences and settings.

Name: Switches
Category: forms
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #choice
Design system: MASTER-UI-ENGINE custom
Variants: default, on/off, disabled
Responsive: yes — scales with text
Dependencies: none (native checkbox input, no JS)
Original source: MASTER-UI-ENGINE (original)
License: MIT

Default

A real <input type="checkbox"> stretched over the whole row and made transparent: the browser does the toggling, the sheet moves the knob. Use a switch only where the change takes effect immediately — a checkbox plus a submit button is the right pattern for a form.

Motion

The knob slides on --duration-base with --ease-spring, so it overshoots by a hair and settles — the overshoot is what makes the state change feel physical. Under prefers-reduced-motion the movement tokens collapse to zero and the knob jumps instantly, because the sheet never hardcodes a time.

Responsive behavior

The track is a fixed 44×24px so the knob travel never changes, while .switch is a wrapping flex row with a --control-h minimum height: the label drops below the track on a narrow phone instead of pushing the row sideways.

Accessibility

  • Role switch conveyed by a native checkbox plus its wrapping <label>
  • Checked state reflects on/off and is announced automatically
  • Focus ring lands on the visible track via input:focus-visible + .track
  • The track is decorative and marked aria-hidden
  • Disabled switches are non-focusable and dimmed
Markup
<label class="switch">
  <input type="checkbox" id="dark-mode">
  <span class="track" aria-hidden="true"></span>
  <span class="switch-label">Dark mode</span>
</label>

<label class="switch">
  <input type="checkbox" id="notifications" checked>
  <span class="track" aria-hidden="true"></span>
  <span class="switch-label">Push notifications</span>
</label>
