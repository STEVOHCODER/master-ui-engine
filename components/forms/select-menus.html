Select Menus

Compact dropdowns for choosing one option from a list.

Name: Select Menus
Category: forms
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #fields
Design system: MASTER-UI-ENGINE custom
Variants: default, with error, disabled, custom-styled
Responsive: yes — full-width on mobile
Dependencies: none (native <select>)
Original source: MASTER-UI-ENGINE (original)
License: MIT

Default

A styled native select, wrapped in the same .field column as every other control. Nothing here opens or closes a menu — the browser owns the option list, which is why the styling only touches the closed box.

Change your plan anytime.

States

The state class sits on the .field wrapper: is-error turns the border and the message red in one step, and :disabled gives the control a sunken surface.

Please select a department.

Responsive behavior

Selects expand full-width; the sheet gives them width:100% and min-width:0, so a long option label ellipsizes inside the native control rather than widening the page. On touch devices the closed box grows to --control-h-lg, and the native dropdown still opens on tap.

Accessibility

  • Native <select> is keyboard and screen-reader friendly; appearance:none does not change that
  • Every control has a <label> joined by for/id
  • Error state uses aria-invalid="true" plus aria-describedby on the message
  • Visible focus ring from the sheet; the decorative chevron is aria-hidden and ignores clicks
  • color-scheme: dark from the engine paints the open option list in the dark palette
Markup
<div class="field">
  <label class="field-label" for="plan">Subscription plan</label>
  <select id="plan">
    <option>Starter — $19/mo</option>
    <option>Professional — $49/mo</option>
  </select>
  <p class="field-helper">Change your plan anytime.</p>
</div>

<div class="field is-error">
  <label class="field-label" for="department">Department</label>
  <select id="department" aria-invalid="true" aria-describedby="department-msg">
    <option>Select a department</option>
  </select>
  <p class="field-msg" id="department-msg">Please select a department.</p>
</div>
