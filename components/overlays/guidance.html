Guidance

The two surfaces that sit on top of the product rather than inside it: a coachmark tour that spotlights what it is talking about, and a float button dock that stays within thumb reach.

Name: Guidance
Category: overlays
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #guidance (+ #cards, #display, #badges, #buttons, #utilities)
Behaviour: page script - step order, Escape, focus, dock reveal
Variants: tour step 1-4, card below, card above, end-aligned; float default, primary, labelled, dock
Responsive: yes - card capped at 100% of the stage, dock gutter tightens below 640px
Dependencies: none

Card anatomy

Out of the stage the card is a normal block in the flow, which is how it can be shown bare: the counter, the title, the body and the action row are the only parts, and the notch is a single rotated square so the card needs no wrapper for its arrow.

Step 1 of 4

Below the target

The default placement: the notch points up at whatever is being taught and the card hangs below it.

Used when the target sits in the top half of the surface.

Step 3 of 4

Above the target

Add .tour-top and the card opens upward, which keeps a step near the bottom of a panel inside the frame.

The notch flips with the card, so the pair never drifts apart.

Float buttons

Forty-four pixels, circular, and a label when an icon would be a guess. The dock in the lower corner of this page is the same component: scroll down and it rises into place, and stacking is only a column, so a second action costs no new position.

The dock shape, shown in place. .float-btn-group is the same column pinned to the viewport corner - see it in the lower right of this page once the page has scrolled.

How it is put together

  • The spotlight is a box-shadow on the target with a 9999px spread, clipped by .tour-stage - no overlay element, so the ring cannot fall out of step with the control it highlights
  • Only the open step paints: a step is a .tour wrapper and .is-open moves between them, so the tour is one state variable, not four positioned cards
  • Every card is a role="dialog" labelled by its own title, and Back, Skip and Next are real buttons, so the tour is operable from the keyboard alone - Escape closes it and returns focus to the replay control
  • Steps 3 and 4 use .tour-top so a target near the bottom of the stage still has its card inside the clipped frame
  • The dock is position: fixed and reveals with the shared reveal composite; it is hidden rather than absent at the top of the page, so it never covers the masthead
  • The scrim is a semantic token, so the same rule reads correctly in both themes without a dark-mode block
