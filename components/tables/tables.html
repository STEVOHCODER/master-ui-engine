Responsive behavior

Never shrink cells to fit. .table-wrap is the scroll container and .table keeps min-width: 40rem, so a narrow phone pans the table sideways with the header still sticky, and the page itself never overflows at 320px.

Accessibility

  • Describe the table with <caption> or aria-label (both are shown above)
  • Scope headers with <th scope="col">
  • Striping is decoration only — status is carried by text, never color alone
  • Sortable headers are keyboard reachable and publish aria-sort as the order changes
Markup
<div class="table-wrap">
  <table class="table table-striped">
    <caption>Active projects</caption>
    <thead>
      <tr>
        <th scope="col">Project</th>
        <th scope="col" data-sort>Status</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Dashboard redesign</td>
        <td><span class="badge badge-success">Active</span></td>
      </tr>
    </tbody>
  </table>
</div>
