Density and states

The same frame carries the two states a data table spends most of its life in. .table-compact is the density modifier from #region tables; the check and caret cells keep their 44px target either way, so only the text rows tighten.

How it is put together

  • Rows are tr siblings; each data row is followed by its detail row, which is hidden until the caret or the Details button opens it
  • Sorting cycles none - asc - desc and republishes aria-sort on the th, which is the element assistive tech reports as the column header
  • The header checkbox is indeterminate when some but not all visible rows are ticked, so "select all" never lies
  • The filter menu closes on Escape and on an outside click, and keeps focus inside the menu while boxes are ticked - Apply is what commits
  • Pagination, the page-size select and the row count all read from the filtered set, so the footer can never disagree with the body
  • Status is carried by the badge label, not by its colour, and amounts use tabular figures so the column sums by eye
