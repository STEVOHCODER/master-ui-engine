Guidelines

  • Always include a clear heading and a helpful description
  • Offer a primary action that moves the user forward
  • Avoid dead ends — every empty state should have an escape route
  • Use an illustration or icon sparingly to add warmth

Accessibility

  • Icons are decorative (aria-hidden); meaning is in the text
  • Primary action is a real button, keyboard reachable
  • Heading describes the state clearly
  • The panel enters with mue-fade-in on --duration-slower; under prefers-reduced-motion the movement token collapses to zero
