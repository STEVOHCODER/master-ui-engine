Error States

Communicate failures clearly and provide a path to recover.

Name: Error States
Category: feedback
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #feedback (panel) + #fields (inline error)
Variants: page error, form error, action error
Responsive: yes — card stacks on mobile
Dependencies: none
Original source: MASTER-UI-ENGINE (original)

Page error

Something went wrong

We couldn’t load your projects. Please refresh the page or contact support if the problem persists.

Refresh

Form error (inline)

Please fix the errors below.

Enter a valid email address.

Guidelines

  • State what happened in plain language, no jargon
  • Offer a concrete next step (refresh, retry, contact support)
  • Don’t blame the user
  • Pair color with an icon and clear text

Accessibility

  • Page-level errors use role="alert"
  • Inline errors are associated with inputs via aria-describedby, and the input carries aria-invalid
  • Focus moves to or near the error when it appears
  • Color never carries the message alone: the icon and the wording say it too. Tints come from --tint-error, so the panel stays legible in the dark theme
Markup
<div class="error-state" role="alert">
  <div class="empty-icon" aria-hidden="true">
    <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">…</svg>
  </div>
  <h2 class="empty-title">Something went wrong</h2>
  <p class="empty-desc">We couldn’t load your projects.</p>
  <button class="btn-primary" type="button">Retry</button>
</div>

<div class="field is-error">
