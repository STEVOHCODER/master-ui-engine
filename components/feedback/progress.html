Determinate

The fill reads its value from the --value custom property, so a single style change moves the bar and the shared width transition does the rest.

Accessibility

  • Use role="progressbar" with aria-valuenow / valuemin / valuemax, updated as the value changes
  • The percent label is associated via aria-labelledby
  • Color is not the only indicator of state — the label and the number say it too
  • The fill transition runs on --duration-slower with --ease-out-expo; the indeterminate sweep is driven by --duration-slowest, so both stop moving under prefers-reduced-motion
Markup
<div class="progress-group">
  <div class="progress-label">
    <span id="upload-label">Upload</span>
    <span class="percent">65%</span>
  </div>
  <div class="track" role="progressbar" aria-labelledby="upload-label"
       aria-valuenow="65" aria-valuemin="0" aria-valuemax="100">
    <div class="bar" style="--value:65%"></div>
  </div>
</div>

<!-- indeterminate -->
<div class="track progress-indeterminate" role="progressbar" aria-label="Working">
  <div class="bar"></div>
</div>
