Loading Skeletons

Placeholder shapes that indicate content is loading, reducing perceived wait time.

Name: Loading Skeletons
Category: feedback
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #feedback
Variants: text, title, avatar, card body, button, image
Responsive: yes — fluid widths

Usage

Show skeletons while data fetches, then replace with real content. Keep the same layout so there is no layout shift.

Accessibility

  • Announce loading state to screen readers (aria-live="polite")
  • Replace skeletons with real content and move focus appropriately
  • The shimmer is a sweep on ::after, timed by --duration-slowest and --ease-in-out; prefers-reduced-motion switches the animation off
