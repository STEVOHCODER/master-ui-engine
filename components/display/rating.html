Rating

Two components wearing the same stars. The read-only version is a labelled graphic next to a number; the interactive version is a radio group that takes a score with the keyboard alone, and neither needs JavaScript.

Name: Rating
Category: display

Variants: read-only with a label, half star, score plus count, radio group

Read-only

The star row is decoration; the score is the sentence. .rating carries role="img" and an aria-label that spells the number out, so a screen reader says "4 out of 5 stars" and never counts five glyphs and a gap.

Rate this kit

A real radio group: five inputs, five labels, no wrapper div per star. Tab enters the group, Right and Up raise the score, Left and Down lower it, and Space commits it. The chosen value is the one that submits with the form, which is the part a click-handler rating never gets right.

Accessibility

  • Read-only ratings are role="img" with an aria-label such as "4 out of 5 stars"; the glyphs inside are aria-hidden
  • The interactive version is five radios in natural 1-5 order, so arrow keys move in the direction the stars are drawn
  • Each input keeps an .sr-only name ("3 stars"), so the group is operable with the screen reader's own form controls, not a custom widget
  • :focus-visible rings the star itself, never the clipped 1px input
  • Stars are 44px squares; the empty state uses --text-tertiary, measured at 5.07:1 on the light surface and 7.35:1 on the dark one, so the unfilled slots stay findable at the 3:1 non-text threshold
  • Half steps are only ever shipped next to a numeric score, never as the only signal
