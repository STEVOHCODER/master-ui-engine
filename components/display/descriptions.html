Descriptions

Read-only label/value pairs for detail panels, order summaries and settings pages - the surface that sits under a table row once you expand it.

Name: Descriptions
Category: display
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #descriptions (+ #badges, #display, #choice, #buttons)
Variants: default, bordered, stacked, sm, lg
Columns: data-cols="1" | "2" | "3"; collapses to 1 at 640px
Responsive: yes - one column on a phone
Dependencies: none
Original source: MASTER-UI-ENGINE (original)
License: MIT

Default (two columns)

A dl with one div.descriptions-item per pair. The wrapper is display: contents, so the dt and dd join the parent grid themselves and every label column lines up across rows.

Accessibility

  • Pairs are dt / dd inside a dl, so a screen reader announces the term and its definition in order
  • The div wrapper around each pair is valid HTML and is transparent to the a11y tree here, because display: contents leaves no box of its own
  • Status is carried by the badge text, never by its colour alone
  • Decorative avatar initials are aria-hidden; the name is written beside them
  • Long values wrap inside their own column instead of pushing the label off the grid
