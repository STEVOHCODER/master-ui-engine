Notifications

Toasts and alerts that communicate system status without interrupting flow. A toast is markup with a data-toast pointer: the script clones it into the stack, animates it in, and removes it again.

Name: Notifications
Category: notifications
Framework: Vanilla HTML/CSS/JS
Defined in: styles/components.css #notifications
Behaviour: styles/mue.js — [data-toast], .toast .toast-close
Variants: success, error, warning, info, inline alert
Responsive: toast width min(24rem, 100%); trigger row wraps
Dependencies: none

Inline alert

An alert stays where it happened and needs no script: same icon/title/message slots, tinted by the variant class.

Behavior

  • Toasts auto-dismiss after 4 seconds (data-dismiss)
  • Close button dismisses immediately, with the same slide-out
  • Multiple toasts stack vertically inside the region
  • Nothing is focus-stealing: a toast never traps the keyboard

Accessibility

  • Inline alerts and toasts use role="alert" so the text is announced
  • Toast icons are decorative (aria-hidden) with a text title beside them
  • Colour plus icon conveys meaning, never colour alone
  • The dismiss control is a real button with an aria-label and a visible focus ring
  • Under prefers-reduced-motion the slide collapses and only the fade remains
Markup
<button class="btn-primary" type="button" data-toast="#toast-success">Success</button>

<div class="toast toast-success" id="toast-success" data-dismiss="4000" role="alert" hidden>
  <span class="toast-icon" aria-hidden="true">&#10003;</span>
  <div class="toast-body">
    <span class="toast-title">Saved</span>
    <span class="toast-msg">Changes saved successfully.</span>
  </div>
  <button class="toast-close" type="button" aria-label="Dismiss">&times;</button>
</div>
