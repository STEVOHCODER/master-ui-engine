How to read this honestly

  • Counted per hit: the page path, a two-letter country from Vercel’s request header, the referrer hostname, and a random id each browser keeps in localStorage.
  • Never stored: IP address, user agent, full referrer URL, query strings, form contents or the code a visitor copies. Library searches are counted, but the words typed are dropped by /api/track before anything is written.
  • “Visitors” counts distinct device ids, so one person on two devices reads as two. It is a floor on reach, not a headcount.
  • Bot-shaped user agents are rejected at /api/track, so the traffic here is real browsers rather than crawler noise.

This console is served behind a signed, HttpOnly session cookie and the stats API re-checks it on every read, so the URL alone grants nothing.
