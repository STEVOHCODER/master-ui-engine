How to read this honestly

  • Counted per hit: the page path, a two-letter country from Vercel’s request header, the referrer hostname, and a random id this browser keeps in localStorage.
  • Never stored: IP address, user agent, full referrer URL, query strings, form contents or the code a visitor copies. Library searches are counted, but the words typed are dropped by /api/track before anything is written.
  • “Visitors” counts distinct device ids seen in the window, so one person on two devices reads as two. It is a floor on reach, not a headcount.
  • Details, including how to get your own rows deleted, are in the privacy notice.

This page is not protected by itself: anyone holding the URL can read it, and /api/stats serves the same numbers as JSON. Turn on Vercel’s Deployment Protection and leave /api/track and /api/subscribe excluded — the steps are in DEPLOYMENT.md.
