The library · live previews

Fifty-four resources, each one running in this browser.

This page is not a gallery of screenshots. Every card below is an entry in the repository's own catalog, and every preview is the file itself — the same HTML, CSS and tokens you would copy into a project. Search matches the wording in the audit notes too, so you can look for “dark toggle” or “WCAG AA” and get the entries that actually say it.

The Framework facet narrows to the entries that exist as more than HTML: all 33 components have React, Vue and Web Components source in frameworks/, labelled stable with the check that earned the label attached. Open the framework tab on a preview to read that binding’s source, install path, contract and verification note — or to see it say plainly that Svelte and Angular have no source yet.
