The workflow is the product

AGENTS.md spells out the ten steps every agent follows. Here is the part that actually decides the outcome.

1

Search before you build

Filter showcase/data/component-catalog.json by category and variant. 46 entries, all searchable by name or path.

2

Open it in the lab

The lab renders the real file, so you see the component, its variants and its responsive behaviour before you commit to it.

3

Copy the markup verbatim

Never retype from memory. The preview file contains the exact HTML that produced what you are looking at.

4

Link one sheet, or lift just its rules

Every class is defined in styles/components.css. Copy + CSS in any preview hands you only the #region blocks that snippet uses — inline them, or link the sheet once.

5

Re-theme with primitives

Override --color-primary-500 and the grayscale ramp. Semantics, dark mode and every component follow automatically.

Ten token files, one import

Primitives are raw HSL triplets. Semantics resolve to complete colors. That split is what makes a single engine.css link enough.

Override once, re-brand everything

:root {
  --color-primary-500: 262 83% 58%;   /* your brand purple */
  --color-gray-50:     260 30% 98%;   /* warm neutral surfaces */
  --radius-base:       0.75rem;
  --font-sans: "Geist", ui-sans-serif, system-ui, sans-serif;
}

Semantics (--bg-surface, --text-secondary, --primary-fg) and themes/dark.css both derive from those primitives, which is why brand overrides survive the theme flip.

One selector. html.dark re-points the grayscale primitives, lifts the brand blues, brightens the semantic states and deepens the shadows. Components never carry dark rules, which is why the ramp can be mirrored without auditing 46 files again.
